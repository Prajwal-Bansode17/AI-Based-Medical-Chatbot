**MEDIQ** is a continuously growing, bilingual (Hindi-English) question-answering dataset collected from a real-world AI chatbot deployed at a public Indian medical university. It captures authentic user queries about medical education, hospital services, admissions, appointments, and university administration.

## Key Features

- **Real-world queries**: Authentic questions from actual chatbot users (not synthetic)
- **Bilingual**: Hindi, English, and code-mixed (Hinglish) queries with language labels
- **Continuously growing**: Updated daily with new interactions
- **Anonymized**: Zero personally identifiable information (PII) collected — no login, no names, no emails, no IP addresses
- **Consented**: All entries collected under explicit user consent with timestamps

## Data Format

Each entry contains the following fields:

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Unique identifier |
| `question` | string | User's question (original text) |
| `answer` | string | AI chatbot's response |
| `timestamp` | string | ISO 8601 timestamp of the interaction |
| `consent` | boolean | Whether the user consented to data sharing |
| `consentTimestamp` | string | ISO 8601 timestamp of when consent was given |
| `language_detected` | string | Heuristic language: `en`, `hi`, or `hi-en` |
| **AI-Enriched Fields** | | *Generated by LLM analysis (Groq Compound)* |
| `ai_language` | string | AI-detected language: `en`, `hi`, `hi-Latn`, `hi-en`, `hi-Latn-en` |
| `ai_language_confidence` | float | Language detection confidence (0.0–1.0) |
| `ai_intent` | string | User intent: `information_seeking`, `navigation`, `scheduling`, `complaint`, `greeting`, `feedback`, `off_topic` |
| `ai_medical_relevance` | string | Medical relevance: `high`, `medium`, `low`, `none` |
| `ai_sentiment` | string | Sentiment: `positive`, `neutral`, `negative`, `frustrated` |
| `ai_question_translated_en` | string | English translation of the question |
| `ai_answer_quality` | string | Answer quality: `comprehensive`, `adequate`, `partial`, `deflected` |
| `ai_topic_tags` | array | Specific topic tags (1–3 per entry) |
| `ai_requires_followup` | boolean | Whether the query likely needs more info |
| `ai_user_type_guess` | string | Inferred user type: `patient`, `student`, `faculty`, `visitor`, `staff`, `unknown` |

## Quick Start

### Python

```python
import json
import pandas as pd

# Load from JSON
with open("data/mediq_full.json") as f:
    dataset = json.load(f)

print(f"Total entries: {dataset['totalEntries']}")

# Or load from CSV
df = pd.read_csv("data/mediq_full.csv")
print(df.head())

# Filter by language
hindi_qs = df[df["language_detected"] == "hi"]
english_qs = df[df["language_detected"] == "en"]
codemixed_qs = df[df["language_detected"] == "hi-en"]
```

## Use Cases

This dataset is useful for research in:

- **Medical QA systems**: Training and evaluating medical question-answering models
- **Chatbot evaluation**: Understanding real-world user interaction patterns

- **User behavior analysis**: How users interact with AI chatbots in healthcare settings

## Ethics Statement

- **No PII collected**: The chatbot does not require login, registration, or any personal information. No names, emails, phone numbers, IP addresses, or device identifiers are collected.
- **Consent**: All interactions are collected under explicit user consent. The chatbot displays a mandatory consent/privacy clause before use.
- **Anonymization**: Data is inherently anonymous — there is no way to re-identify any individual from the dataset.
- **Compliance**: Fully compliant with India's Digital Personal Data Protection (DPDP) Act 2023. Anonymous data is exempt from the Act's scope (Section 2). No clinical or health research data is included — the dataset contains only administrative and informational queries about a medical university.
- **Safety**: The chatbot actively warns users not to share personal health details, Aadhaar numbers, or phone numbers, and redirects medical queries to qualified healthcare providers.
